# Submission requirements

Source: `live.sotonship.space/judging` (section "What to submit") plus the "Track rules" and "Deliverables and pitch" sections of each brief. Fetched 16 October 2026.

## Where and when

- Everything goes on the **team page** on `live.sotonship.space`, reachable after logging in with an emailed code or the badge access code.
- **Submissions lock at Sunday 18 October, 13:00.** "No extensions." The organisers only extend for a team in special circumstances, at their discretion.
- **A team whose submission is incomplete at the lock is not shown in Stage 1**, which means no pitch slot and no score.
- Late submissions can still demo but are not judged.
- Partner prizes are **opt-in at submission**, so the opt-in box has to be ticked there rather than mentioned on stage.

## The three required deliverables

### 1. Pitch video (YouTube link)

- Uploaded to YouTube and submitted as a link. **Public or unlisted.**
- **Between 1:00 and 3:00 long.**
- It must show the real product working: a screen recording of the live product. **Mock-ups or slides alone do not count as a demo.**
- State the pitch format: either a video that uses the whole slot, or a shorter video with the rest of the slot delivered as a live talking pitch. Tell the organisers **which**, and give the **video length**.

### 2. Project summary (up to 150 words)

Must cover: the user and the problem, why it matters, the solution, and how it could scale.

### 3. GitHub repository (public)

The README must cover:

- Setup
- Data sources, **with dates and licences**
- What the AI does
- **What was AI-generated or pre-existing**
- Test results
- Known limits

### Optional but encouraged

A live link or run instructions.

## Suggested 3-minute pitch structure

| Time | Content |
|---|---|
| 0:00–0:20 | The user and their problem, with one piece of evidence |
| 0:20–1:40 | Demo of the core task, start to finish (this part must be in the video) |
| 1:40–2:10 | Why AI: what it does, and proof it beats a simple approach |
| 2:10–2:45 | The business: who pays, what it costs, how it grows |
| 2:45–3:00 | Limits and trust, then what would be built next |

## Checklist to run before 13:00 on Sunday

- [ ] Core task runs end to end, live, on real data
- [ ] Screen recording of the live product, 1:00–3:00, uploaded to YouTube as public or unlisted
- [ ] The demo shows at least one failure case (missing data, stale source, input outside coverage)
- [ ] A baseline comparison exists for the AI step, with the numbers written down
- [ ] 150-word summary written, and under 150 words
- [ ] Public GitHub repo, with the entry built during the event only
- [ ] README covers setup, data sources with dates and licences, what the AI does, what was AI-generated, test results, known limits
- [ ] No API keys, tokens or passwords committed
- [ ] No real customer or personal data committed; synthetic data labelled as synthetic
- [ ] Any safety, health, legal or financial guidance links to an official source (FCA, MoneyHelper, council, EA, government) rather than writing its own
- [ ] Partner prize opt-in ticked if wanted
- [ ] Pitch format stated: video-only or video plus live pitch, with the video length
- [ ] Data sources dated and credited in the README
- [ ] Everyone on the team is on the team page

## Team page mechanics that affect the pitch

- While a team pitches, anyone can post and upvote questions on its team page; the moderator reads the top ones, judges' questions first.
- The panel in Stage 2 supplies its own input to the 2:00 live demo, so the product needs to handle an unseen input, not only the rehearsed path.
- Investing in VC for a Day is done by the audience on the team pages, closes a few minutes after the last pitch of the track, and the last save counts.
